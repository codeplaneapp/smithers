---
title: Quickstart
description: Scaffold and run a Smithers workflow in two commands.
---

<Note>
  The coding agent runs these commands. Agents: run them on the human's behalf, never
  hand them off. Humans: ask your agent for the outcome; it runs these for you. Exception:
  type the initial `init` yourself, before an agent exists.
</Note>

<Steps>
  <Step title="Scaffold a project">
    `init` creates `.smithers/`: authoring workflows, DDD spec/UI closure, and agent
    config. `--template <id>` requests a create-workflow-driven starter with follow-up
    notes, not an archived workflow. Browse template IDs with
    `bunx smthrs starters`.

    ```bash
    bunx smthrs init
    bunx smthrs init --template idea-to-tickets
    ```
  </Step>
  <Step title="Run a workflow">
    Point a seeded workflow at a prompt and Smithers starts a durable run.

    ```bash
    bunx smthrs workflow run create-workflow --prompt "Add a rate-limiting workflow"
    ```
  </Step>
  <Step title="Inspect the run">
    Watch run state, tail the event log, and read structured output as it executes.

    ```bash
    bunx smthrs ps
    bunx smthrs inspect RUN_ID
    bunx smthrs logs RUN_ID --tail 20
    ```
  </Step>
  <Step title="Resume after a crash">
    Every completed step persists, so a crashed or stopped run resumes from its last
    checkpoint.

    ```bash
    bunx smthrs workflow run create-workflow --run-id RUN_ID --resume true
    ```
  </Step>
</Steps>

<Tip>
  `init` auto-installs the smithers skill for your coding agents. Ask for the outcome
  (*"orchestrate an agent to add rate limiting and keep iterating until the tests pass"*)
  and your agent runs Smithers for you.
</Tip>
