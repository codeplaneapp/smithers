This material is now in [Recipes](/recipes#vcs-revert--per-attempt-snapshots).

Smithers prefers `.jj` over `.git` in colocated repos: pure Git repos work without JJ installed but can't use `revert`. The JJ pointer in `_smithers_attempts.jj_pointer` is the immutable **commit ID**, not the change or operation ID, so it pins the exact captured workspace state. On worktree-run resume, Smithers auto-rebases onto the base branch (default `main`) and continues even if that rebase fails.
