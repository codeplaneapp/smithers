Smithers defaults to Codex whenever usable Codex authentication is available:

| Work | Model |
|---|---|
| Planning, orchestration, review, and the hardest reasoning | `gpt-5.6-sol` |
| Mid-tier judgment, validation, and tool-focused work | `gpt-5.6-terra` |
| **All implementation**, research, and cheap or high-volume work | `gpt-5.6-luna` |

Pin the exact tier IDs above instead of the floating `gpt-5.6` alias. Luna is
the implementation default even for large changes; Sol is reserved for
planning, orchestration, and review. For independent review signals, pair Sol's
review with Terra validation rather than introducing a different provider.

When Codex is unavailable, Smithers falls back to detected Claude, Kimi,
Gemini, or other compatible adapters. Explicit provider-specific workflows
remain supported. The [SOTA model registry](/reference/sota-models) lists the
current defaults and badges and is refreshed by a daily research job.
