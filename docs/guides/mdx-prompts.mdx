This material is now in [Recipes](/recipes#mdx-prompt-with-auto-injected-schema).

When a `<Task>` child is a JSX/MDX element and an output schema is set, Smithers auto-injects `props.schema` with a JSON example derived from the Zod schema. If running tests, also register `mdxPlugin()` in the `[test]` preload.

In `.mdx` prompt files, prose resembling JSX or HTML parses as JSX; wrap examples like `<Parallel maxConcurrency={N}>` in backticks or a code block so the module still compiles and exports its default prompt component.
