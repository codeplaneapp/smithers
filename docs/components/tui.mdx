---
title: <TUI>
description: Declare a workflow-owned React terminal UI for OpenTUI-capable clients.
---

`<TUI>` is the terminal counterpart to [`<UI>`](/components/ui): it declares
the React entry an OpenTUI-capable client should render for terminal
monitoring. It renders nothing in the workflow graph; clients read the
declaration from workflow metadata and pick the terminal host.

```tsx
import { TUI, Workflow } from "smithers-orchestrator";

export default smithers(() => (
  <Workflow name="terminal-view">
    <TUI entry="./tui/terminal-view.tsx" title="Terminal View" />
    {/* normal workflow nodes */}
  </Workflow>
));
```

## Props

`<TUI>` accepts the same view fields as `<UI>`: `entry`, `source`,
`exportName`, `title`, `props`, and literal `children`. Prefer `entry` for a
real terminal app, so the OpenTUI host loads the full React component tree.
