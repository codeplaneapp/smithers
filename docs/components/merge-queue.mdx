---
title: <MergeQueue>
description: Queue child tasks so at most maxConcurrency run; defaults to single-lane.
---

```ts
// Props
import { MergeQueue } from "smithers-orchestrator";

type MergeQueueProps = {
  id?: string;
  maxConcurrency?: number;  // default: 1
  priority?: number;        // default: 1000; inherited by descendant tasks
  skipIf?: boolean;
  children?: ReactNode;
};
```

```tsx
<MergeQueue maxConcurrency={2}>
  {items.map((it, i) => (
    <Task key={i} id={`t${i}`} output={outputs.outputC}>{{ value: i }}</Task>
  ))}
</MergeQueue>
```

## Notes

- Innermost group determines the effective cap for its descendants.
- Tasks outside the queue are unaffected by its limit.
- Descendant tasks inherit priority `1000` by default, so ready-to-land queue
  work outranks ordinary priority-`0` work when both compete for scarce slots.
  Set `priority` on the queue to change that default, or on a child task to
  override it. Priority never bypasses dependencies or concurrency caps.
