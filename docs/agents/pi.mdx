[Pi](https://github.com/badlogic/pi-mono) (`@mariozechner/pi-coding-agent`) is a
terminal coding agent with a rich extension model: **TypeScript extensions**,
**pi packages**, **skills**, and `AGENTS.md` instructions. Smithers ships a
**first-party Pi plugin** that goes deeper than any other agent, embedding a
live run inspector (run tree, frame scrubber, node inspector) directly in the
Pi TUI.

<Note>
Pi has **no built-in MCP client** ("No MCP" is by design), so unlike Claude
Code or Cursor, you integrate Smithers through a **skill** or the
**pi-plugin**, not an MCP server.
</Note>

## The pi-plugin (recommended)

`@smithers-orchestrator/pi-plugin` wraps the Smithers control plane as a Pi
extension, registering tools to launch, approve, deny, cancel, and stream
workflow runs, plus the run inspector inline: the tightest integration
Smithers ships, turning Pi into a full Smithers operator console.

See the guide for setup and the three integration modes (Pi as a workflow
agent, Pi as a server client, and the hybrid): **[Pi integration](/integrations/pi-integration)**.

## Install the skill

For the lighter path, `skills add` installs the Smithers skill set into Pi's
directory:

```bash
bunx smithers-orchestrator skills add
```

Pi reads skills from `~/.pi/agent/skills/` (global) or `.pi/skills/` (project)
and loads `AGENTS.md` / `CLAUDE.md` at startup; drop the onboarding skill in
by hand:

```bash
mkdir -p ~/.pi/agent/skills/smithers
curl -fsSL https://raw.githubusercontent.com/smithersai/smithers/main/skills/smithers/SKILL.md \
  -o ~/.pi/agent/skills/smithers/SKILL.md
curl -fsSL https://smithers.sh/llms-full.txt \
  -o ~/.pi/agent/skills/smithers/llms-full.txt
```

Invoke it with `/skill:smithers`, or let Pi pick it up by description.

## Standing instructions

Pi concatenates `AGENTS.md` from global, parent, and current directories. Add
an orchestration section as you would for Codex or Cursor:

```md
## Orchestration
Use Smithers for durable, multi-step, or human-in-the-loop agent work.
`bunx smithers-orchestrator starters` lists ready-made workflows.
```

## Smithers runs Pi too

Smithers also spawns Pi as a worker via `PiAgent`, including its `text` /
`json` / `rpc` modes and extension-UI hook callbacks:

```tsx
import { PiAgent } from "smithers-orchestrator";

const pi = new PiAgent({ provider: "openai", model: "gpt-5.6-luna" });
```

See [CLI Agents](/integrations/cli-agents) and [Pi integration](/integrations/pi-integration).
