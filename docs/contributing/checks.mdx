---
title: "Checks"
description: "Run the production audit, lint, typecheck, and test gates before opening a pull request."
---

Run this before a pull request:

```sh
pnpm verify
```

It runs, in order:

```sh
pnpm audit:prod
pnpm lint
pnpm -r typecheck
pnpm --filter ./.smithers typecheck
pnpm typecheck:examples
pnpm typecheck:evals
pnpm test
```

`pnpm audit:prod` rejects new production advisories, expired security exceptions,
denied licenses, and unreviewed or stale unknown-license metadata. Exact reviews
for packages that omit metadata cite immutable upstream sources in
`.github/production-license-reviews.json`. `pnpm -r typecheck` runs every
workspace typecheck; the following commands cover the workflow pack, examples,
and evals explicitly.

`pnpm lint` checks `apps/*/src`, `apps/*/tests`, `packages/*/src`, `packages/*/tests`, and `.smithers`.

`pnpm test` runs workspace tests.

Do not use root `tsc --noEmit` as the complete pre-PR gate.
