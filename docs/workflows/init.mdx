title: init
description: System workflow behind `bunx smthrs init`: installs or refreshes the .smithers workflow pack and curated agent skills as a durable, replayable run.
---

`init` is a **system workflow** (`system: true`): internal plumbing for
Smithers' durable processes, hidden from default listings (`workflow list`
without `--system`, the interactive picker, MCP `list_workflows`, gateway
`listWorkflows`) but explicitly runnable.

The first-ever `bunx smthrs init` bootstraps the pack imperatively (itself a
pack file, it can't run before existing). Every later
non-interactive `bunx smthrs init` instead runs through the engine, making each
pack refresh a durable, replayable, step-recorded run; if it can't load (stale
pack, missing deps), the CLI falls back to the imperative scaffold.

```bash
bunx smthrs workflow run init --input '{"force":false}'
```

## Stages

1. **install-pack**: deterministic (no agent), calls the CLI's
   `initWorkflowPack` to write missing pack files, skip existing ones, and
   flag files drifted from bundled templates (`changed`). Gated by `force`.
2. **refresh-skills**: updates the curated `smithers` skill per detected
   coding agent, removing retired installs; disable via `refreshSkills: false`.
3. **output**: surfaces `{ written, skipped, changed, skills }`.

## What init writes outside the project

`init` reads as project-local, but the **refresh-skills** stage deliberately
writes machine-wide: it copies the curated `smithers` skill (`SKILL.md` +
`llms-full.txt`) into the skills directory of every coding agent it detects on
this machine.

| Agent | Directory |
| --- | --- |
| Claude Code | `~/.claude/skills/smithers` |
| Pi | `~/.pi/agent/skills/smithers` |
| Oh My Pi | `~/.omp/agent/skills/smithers` |
| Codex | `~/.codex/skills/smithers` |
| OpenCode | `~/.config/opencode/skills/smithers` |
| Kimi, Amp | `~/.config/agents/skills/smithers` |
| Antigravity | `~/.gemini/skills/smithers` |

Only detected agents are written to, and each write overwrites that folder's
`SKILL.md` and `llms-full.txt`, leaving any other file already in the folder
alone. Skill opt-outs persist in `~/.smithers/skill-deselections.json`.

Pass `bunx smthrs init --no-skill` (or `refreshSkills: false` when running the
workflow) to keep `init` entirely inside the project. Everything else `init`
writes stays under `./.smithers/`, except `bunx smthrs init --global`, which
scaffolds the pack into `~/.smithers` (or `SMITHERS_HOME`) instead.

## Input

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `force` | boolean | `false` | Overwrite existing (non-preserved) pack files with bundled templates. |
| `refreshSkills` | boolean | `true` | Refresh the curated `smithers` skill for detected agents. |
| `skipInstall` | boolean | `false` | Skip `bun install` inside `.smithers/` after scaffolding. |
