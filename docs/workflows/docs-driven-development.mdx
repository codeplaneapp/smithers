---
title: docs-driven-development
description: Maintain a portable living product specification and improve a target repository from it.
---

`docs-driven-development` is the seeded workflow for a repository's living
product specification. A fresh `bunx smithers-orchestrator init` includes a blank
portable starter spec plus the helper/UI closure it needs, not Smithers' own spec.

Run it from the initialized project:

```bash
bunx smithers-orchestrator workflow run docs-driven-development
```

The browser surface is served by the project's Gateway; for cross-run
monitoring, use `bunx smithers-orchestrator monitor` or Gateway `/monitor`.
