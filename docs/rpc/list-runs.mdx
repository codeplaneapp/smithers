---
title: listRuns
description: Gateway RPC for listing runs.
maturity: stable
apiVersion: v1
---

- Method: `listRuns`
- Scope: `run:read`
- Transports: HTTP RPC, WebSocket RPC
- Request: `{ filter?: { status?, limit?, offset?, workflow? } }`
- Response: `RunSummary[]`

Errors are versioned as `v1` and include `InvalidRequest`, `Unauthorized`, `Forbidden`, and `Internal`.

`workflow` filters to runs attributed to that workflow key (gateway-started runs match by registered config key, CLI runs by workflow name). Results order newest first. `offset` skips that many rows after the newest-first sort, so `limit` plus `offset` page the full history server-side; a negative or non-integer `offset` is an `InvalidRequest`.
