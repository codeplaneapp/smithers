---
title: hijackRun
description: Gateway RPC for elevated operator handoff.
maturity: stable
apiVersion: v1
---

- Method: `hijackRun`
- Scope: `run:admin`
- Transports: HTTP RPC, WebSocket RPC
- Request: `{ runId, options? }`
- Response: `{ runId, status: "hijack-ready", sessionId }`

Errors are versioned as `v1` and include `InvalidRequest`, `Unauthorized`, `Forbidden`, `RunNotFound`, and `Internal`.

Scoped above normal run write access, this RPC has the Gateway verify the run exists and return a `sessionId` token the caller (e.g. `bunx smthrs hijack`) uses to attach a terminal, inject commands, or resume the agent conversation.
