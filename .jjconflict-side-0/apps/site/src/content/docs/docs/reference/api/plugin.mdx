## Contract

`FlowsHooks` is open for TypeScript module augmentation and closed for runtime
dispatch. A host supplies an own-property hook catalog and dispatches only that
catalog. The shared catalog contains `config` and `configResolved`; the agent
cell host adds its registry, flow-binding, and model-request waterfalls.

The shared `Plugins` tag and its two layers hold one dispatcher over the
process-wide augmented `FlowsHooks`. `declare module "@smthrs/plugin"` is the
supported extension mechanism for values placed in that tag. A host typed
against a separate hook interface holds its `Plugins.Service<H>` directly and
does not use the shared tag or those layers.

`Resolve.Options.target` defaults to `"engine"`. A plugin with
`apply: "harness"` is dropped by a bare `Kernel.make`; a cell host passes
`{ target: "harness" }`, as `@smthrs/agent` does.

Resolution is once-only. It copies plugin and hook records, freezes handler
records and ordered arrays, and exposes a read-only map facade without
`set`, `delete`, or `clear`. Names compare as exact Unicode strings. Canonically
equivalent spellings remain different names.

Ordering follows Vite exactly. `enforce` sorts the plugin list once into pre,
normal, and post groups, stably within each group. The per-hook `order` then
re-partitions that list for one hook only, so a handler declared
`{ order: "pre", handler }` runs ahead of every normal-order handler even when
its plugin is `enforce: "post"`. Ties keep the resolved plugin order.

Plugin layers compose in resolved order. When two plugin layers provide the
same service tag, the later resolved plugin wins.

## Configuration

Config is a plugin-owned JSON namespace. The root keys `engine`, `retry`,
`store`, and `plugins` are refused because the plugin kernel does not apply
those policies. Records merge recursively; arrays and scalars replace. Every
waterfall result is copied and frozen before the next handler sees it.

Accepted trees are limited to 1 MiB, 64 container edges, 4,096 members, and
8,192 values. Strings are limited to 64 KiB of encoded JSON and keys to 1 KiB.
Both merge operands and the merged result are admitted, so no waterfall step
observes a value beyond those bounds.

Cycles, repeated object references, sparse arrays, accessors, symbols, exotic
prototypes, non-finite numbers, unpaired surrogates, `undefined` members, and
the prototype-control keys `__proto__`, `constructor`, and `prototype` are
refused without executing user accessors. `undefined` is refused rather than
dropped, so `{ endpoint: undefined }` fails with `config_invalid` at that key's
path instead of resolving to `{}`. Omit the key, or write `null`.

Admission reads a value through `Reflect.ownKeys`, `Object.getPrototypeOf`, and
one property descriptor per key. A proxy therefore observes a bounded number of
trap calls, and only the data those traps return is copied: a proxy can place
no accessor, prototype, or behavior in an admitted value, and any trap that
throws refuses the whole tree.

## Resolution and dispatch limits

One kernel accepts at most 256 plugins, 1,024 handlers, 4,096 preset nodes, and
64 nested preset arrays. Plugin and hook names are control-free, well-formed
strings of at most 256 UTF-16 code units that are neither empty nor entirely
whitespace. A declared hook entry is a function or a record whose `handler` is
a function; `undefined` is refused rather than skipped.

Every plugin record, option, and hook entry is validated before `apply`
selection runs, so exclusion cannot hide a malformed plugin. Host-catalog hook
names are checked after selection, so a shared preset carrying `apply:
"harness"` plugins with harness-only hooks still resolves under a bare engine
kernel. The handler bound counts the handlers the kernel dispatches.

Parallel observers run at concurrency 16 by default. `parallelConcurrency`
accepts a positive safe integer through 256. Result ordering remains resolved
handler order. Sequential and waterfall hooks stop on the first failure.
Parallel hooks run every handler and return their failures. First hooks stop on
`Option.some`, return `Option.none` when nobody answers, and refuse any value
that is not an `Option`.

## Cache identity

`cacheEnvironment` is optional. Omitting it keeps sealed activity keys local to
the run and leaves plugin `version` optional. Supplying it requires the complete
`Action.CacheEnvironment` schema and a bounded, non-empty `version` on every
selected plugin. Resolution copies and freezes every layer, capability record,
and capability array, then prepends each selected `name@version` in resolved
order. Both halves percent-escape `%` and `@` first, so the identity is
injective: `a@b` at version `c` and `a` at version `b@c` produce different
layer entries instead of one shared sealed identity. A scoped name reads as
`%40scope/name@1.0.0`. A versionless composition fails with `cache_environment_invalid`
instead of declaring an ambiguous cross-run identity. Invalid or mutable caller
data never reaches `Action.CurrentCacheEnvironment`.

## Failures

All startup and dispatch refusals use `PluginError`.

| Code                        | Meaning                                                                 |
| --------------------------- | ----------------------------------------------------------------------- |
| `duplicate_name`            | Two selected plugins have the same exact name.                          |
| `unknown_hook`              | A plugin declares a hook absent from the host catalog.                  |
| `invalid_plugin`            | A plugin, preset, option, or hook entry has an invalid runtime shape.   |
| `apply_failed`              | An `apply` predicate threw. Its raw failure is not retained.            |
| `config_invalid`            | Config is not bounded strict JSON or uses a reserved policy key.        |
| `cache_environment_invalid` | Cache identity is malformed or incomplete.                              |
| `invalid_hook_result`       | A first hook returned a value other than `Option`.                      |
| `resource_limit`            | Preset, plugin, handler, or concurrency work exceeds a published bound. |
| `hook_failed`               | A hook Effect failed, defected, or returned no Effect.                  |
| `layer_failed`              | A validated plugin layer failed during acquisition.                     |

`configResolved` is a lossy observer boundary. Its failures do not fail kernel
startup; `Kernel.observerErrors` returns them for redacted logging by the host.
