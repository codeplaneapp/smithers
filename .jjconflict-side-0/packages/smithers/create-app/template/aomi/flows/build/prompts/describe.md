# describe

Turn the request into a description of one app.

Answer these, in prose, before any file is planned:

- What does the app do, in one sentence a user would recognize?
- Who opens it, and what do they do first?
- What data does it read, and where does that data come from? Name the chain,
  the contract, or the API.
- What does it write, if anything? A write needs approval; say so here.
- What is out of scope for this build?

Keep it to one screen. If the request is ambiguous on any of the five points,
state the reading you are taking and why, then continue. Do not ask the user a
question you can answer from the request.
