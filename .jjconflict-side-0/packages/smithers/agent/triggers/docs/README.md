# Colocated documentation

This directory, `docs/Manifest.ts`, and the public JSDoc in `src/` own the published
contract for `@smthrs/triggers`. The `Public API` section of
`packages/smithers/agent/triggers/README.md` is generated output.

After editing these sources, run:

```sh
node packages/smithers/agent/triggers/scripts/docs.mjs
```
