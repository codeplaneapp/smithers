# Add responsive layouts for the Smithers Monitor

GitHub: https://github.com/smithersai/smithers/issues/1117

Parent: smithers/smithers-gh-643-make-smithers-monitor-trul-0iz5n9a--add-responsive-accessible-and-resilient-mo-0vi5vil.md

Context: The monitor is a live operational surface that must remain usable from mobile through wide desktop without forced overflow. Acceptance criteria: define tested responsive breakpoints for narrow mobile, tablet, standard desktop, and wide desktop; collapse or reposition the rail and inspector appropriately; keep toolbars, tables, trees, timelines, and modal content usable at narrow widths; contain unavoidable scrolling within the relevant component; verify no document-level horizontal overflow in real browsers.
