# Make monitor pending approvals actionable and stale-safe

GitHub: https://github.com/smithersai/smithers/issues/1123

Parent: smithers/smithers-gh-643-make-smithers-monitor-trul-0iz5n9a--polish-approvals-and-run-actions.md

Context: Operators need a reliable approval inbox for gates across runs. Acceptance criteria: render workflow, full run id, node and iteration, request title/summary, and live wait time; make approve and deny visually distinct; require confirmation with predictable focus behavior for destructive decisions; prevent duplicate submissions with per-approval busy states; show recoverable success and failure feedback; refresh and explain stale approvals without losing operator context; provide accessible names and keyboard coverage for success, failure, cancellation, and stale-approval cases.
