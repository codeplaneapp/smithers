Return exact ordered stagePaths, exact ordered changedPaths, stable patchId, admitted envelope, and iteration. Echo the mechanical tuple only when every field matches; otherwise valid=false. The controller alone creates/amends or lands. Never run Git mutation, push, or GitHub mutation.
