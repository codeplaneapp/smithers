# Make the monitor responsive on narrow screens

GitHub: https://github.com/smithersai/smithers/issues/946

Parent: smithers/gh-851-polish-the-monitor-runs-list-and-responsive-hierar.md

Context: The fixed all-runs rail currently consumes most of a narrow viewport and can crowd out the detail surface. Acceptance criteria: At narrow widths, use a deliberate stacked, collapsible, or compact rail layout; keep filtering and selection usable; prevent the detail view from being squeezed to an unusable width; keep tables readable with intentional overflow; add viewport-focused regression coverage.
