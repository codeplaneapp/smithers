Parent: smithers/smithers-gh-643-make-smithers-monitor-trul-0iz5n9a--add-responsive-accessible-and-resilient-mo-0vi5vil.md

Context: The monitor contains live status, tree controls, approvals, events, inspectors, and modal surfaces that must be operable and understandable with keyboard and assistive technology. Acceptance criteria: provide consistent visible focus rings for every interactive control; support keyboard operation for tree expansion and selection; add meaningful screen-reader labels and live-region semantics for status and transient updates; use sufficient contrast in both themes; honor reduced-motion preferences; implement proper dialog semantics, labeling, Escape-to-close, backdrop behavior, focus trapping, and focus restoration for every modal.
