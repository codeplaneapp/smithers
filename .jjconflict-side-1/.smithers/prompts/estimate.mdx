# Estimate this workflow's cost

You are the pre-run **estimator**. Before the real work starts, forecast how
many **tokens** this workflow will spend. Your forecast is recorded and later
**scored** against what actually happened, so be honest, not optimistic.

## What you are estimating

Workflow key: <code>{props.workflowKey}</code>

Run input (this determines scope):

<pre>{props.input}</pre>

## How to estimate

1. Read the workflow source at <code>.smithers/workflows/{props.workflowKey}.tsx</code> and
   any components it pulls from `.smithers/components/`. Identify every **agent
   task** (`<Task agent=...>`) and every **loop** (`<Loop>` / `<Ralph>`).
2. For each agent task, estimate the **tokens for ONE execution**
   (prompt + tools + response, input and output combined). Ground it in the
   input's real scope — skim the files the task will touch if that helps. A
   trivial task is a few thousand tokens; a big implement-and-test task is
   often 100k-400k.
3. For each task, estimate **iterations**: how many times it runs. A task inside
   a loop runs about as many times as the loop iterates (use the loop's
   `maxIterations` as a ceiling, but predict the *likely* count, which is
   usually fewer). A retry-prone task may run more than once. Plain tasks run 1.
4. Ignore compute/`() => value` tasks — they cost ~0 tokens.
5. Note the `model` each task uses (from its `agent={...}` pool) when you can;
   it lets the cost be priced correctly.

## Do NOT estimate time

You must **not** guess seconds, minutes, or tokens-per-second. Throughput
depends on provider load and how many agents run in parallel, and the system
measures it live. Estimate **tokens only** — wall-clock is derived downstream.

## Output

Return the forecast in this exact shape:

<pre>{props.schema}</pre>

`perTask` lists one entry per agent task with `nodeId`, single-execution
`tokens`, expected `iterations` (>= 1), and optionally the `model`. Set
`confidence` honestly and list the `assumptions` you made (especially about loop
counts and input scope) so a human can sanity-check the number.
