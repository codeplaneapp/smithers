Example · custom sandbox provider

A Smithers workflow executing inside a real stereOS VM

The sandbox body runs in a stereOS mixtape VM under QEMU/KVM. Smithers ships providers for Microsandbox, Daytona, Vercel, AWS, GCP, and Cloudflare, plus local bubblewrap and Docker; this example adds one more through the same seam.

03 / 03

What is exposed

The gateway's RPC surface is not reachable from the internet. The guard is.

Three workflow ids

hello, pipeline, approval-demo. A workflow id from the request is never forwarded.

Server-chosen input

The guard picks each run's input, so a visitor cannot steer what executes in the guest.

Five RPC methods

Named as literals in guard.ts. No method name from a request reaches the gateway.

2 concurrent, queue of 8

Six starts per IP per ten minutes, counted on the Cloudflare edge IP.

256-bit approval token

Minted at start, compared with timingSafeEqual. Nothing else resolves a gate.

Five minute hard cap

The guard cancels the run and frees its slot. Responses are built field by field.

One run, step by step

Excerpts are verbatim from the GCE capture.

  1. stereOS VM

    The host boots the mixtape under QEMU/KVM and waits for the guest to answer on SSH.

    == guest ==
agent
coder-dev
Linux 6.18.33 x86_64
PRETTY_NAME="stereOS dev-f269d96 (coder-dev)"
  2. Smithers

    Smithers starts the run on the host. The workflow holds one node.

    info  starting workflow run engine:run=0ms runId=55c1ccb5-9ddf-4912-82eb-eb35efd69767
      workflowName=workflow
      workflowPath=/home/willcory10_gmail_com/smithers/apps/stereos-site/real/stereos-real.tsx
  3. SSH · provider seam

    The provider bundles the child workflow, uploads it over SSH, and runs the guest launcher.

    #7  +00:00.279  SandboxCreated        🧪 Sandbox created: stereos-vm (stereos)
#8  +00:00.288  SandboxShipped        📦 Sandbox shipped: stereos-vm (163 bytes)
  4. Bun in guest

    The guest's Bun executes the bundle and writes the result the engine collects.

    #12  +00:02.153  SandboxBundleReceived  📥 Sandbox bundle received: stereos-vm (0 patches)
#13  +00:02.156  SandboxCompleted      ✅ Sandbox completed: stereos-vm (finished)
  5. result JSON

    The output is the guest's own report: its OS, kernel, and hostname, none of which exist on the host.

        "os": "stereOS dev-f269d96",
    "kernel": "Linux 6.18.33 x86_64",
    "user": "agent",
    "hostname": "coder-dev",

    The prompt hash reproduces on the host. It shows input and output agree; it is not provenance.
