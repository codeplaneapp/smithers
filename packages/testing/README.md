# @smthrs/testing

Testing and conformance library for flows. It provides layered engine and model doubles, pure plan and journal assertions, restart and parity suites, Vitest adapters, and deterministic score gates.

```sh
npm install @smthrs/testing
```

## Public API

The root entry point exports these namespaces; each is also importable from `@smthrs/testing/<Module>`.

| Module              | Public exports                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Description                                                                     |

| `FlowEngineLike`    | `make`, `layer`, `layerMemory`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Adapts the real flows engine to EngineSubject, including an in-memory bundle.   |
| `HostSuite`         | `CapabilityExpectation`, `HttpTransportExpectation`, `HostProfile`, `HostSuiteCase`, `HostBundle`, `hostSuite`                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Builds host conformance cases from a host bundle and capability profile.        |

```ts
import { Conformance, EngineSubject, TestLayers, Vitest } from "@smthrs/testing"
import { Effect } from "effect"

const test = Vitest.testEffect(TestLayers.unit(engineLayer))
for (const testCase of Conformance.suite()) {
  test.effect(testCase.name, () => Effect.flatMap(EngineSubject.EngineSubject, testCase.run))
}
```

`@smthrs/testing/package.json` is also exported. `internal/*` and nested `*/index` subpaths are not public.
