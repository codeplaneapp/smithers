# Owners.Tree

Generates the per-directory `OWNERS` tree from every package's `owners`
declaration, in the Google format the Smithers landing gate parses. One file
lands in each package directory that declares ownership or is claimed
upstream; the root also lands when the workspace declares default owners. A
package that declares nothing gets no file, because the parser inherits from
the parent directory exactly as the resolver does.

```ts
import { Smithers as S } from "@smthrs/targets"

export const Package = S.Package({
  targets: {
    ownersTree: S.Owners.Tree({})
  }
})
```

```sh
smithers-build lint //:ownersTree
smithers-build //:ownersTree --write
```

## Attributes

| Name   | Type     | Default    | Description                                                     |
| ------ | -------- | ---------- | --------------------------------------------------------------- |
| `file` | `string` | `"OWNERS"` | File name written in each owning package directory. No slashes. |

## Format

Per file, in order:

| Line                                                                       | Source                                                      |
| -------------------------------------------------------------------------- | ----------------------------------------------------------- |
| `# Generated by smithers-build from <pkg>/PACKAGE.ts owners. Do not edit.` | always                                                      |
| `set noparent`                                                             | `noparent: true`                                            |
| `<owner>`                                                                  | one per `owners` entry, `team:<name>` kept as written       |
| `per-file <glob> = <owner>, <owner>`                                       | one per `perFile` rule                                      |
| `agents: <policy>`                                                         | the `agents` default                                        |
| `agents: <policy> <glob>`                                                  | one per `agents` override, in declared order                |
| `<owner>  # upstream-of //pkg`                                             | one per owner of a package claiming this one with `approve` |
| `reviewers: <owner>, <owner>  # upstream-of //pkg`                         | the owners of a package claiming this one with `review`     |

```
# Generated by smithers-build from src/PACKAGE.ts owners. Do not edit.
dzucconi
team:web
per-file *.graphql = team:data
agents: human-approve
agents: auto-land **/*.md
agents: deny Server/**
```

## Channels

| Channel | Type                                                                                       |
| ------- | ------------------------------------------------------------------------------------------ |
| Success | `void`                                                                                     |
| Error   | drift in check mode: `drift in declared emit outputs (run with --write to apply): <paths>` |

## Verbs and cacheability

`build` and `lint`. Build system plans the check form unless `--write` is
passed, and never replays a result.
