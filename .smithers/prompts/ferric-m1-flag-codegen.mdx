## Feature-flag codegen

Implement the feature-flag codegen in the campaign repository at {props.repo}.

Generate Rust constant tables, per release channel — oss-stable and oss-experimental — for all
65 flags, read from the SAME source file React itself reads: `shared/ReactFeatureFlags.js` in
the pinned checkout at {props.reactRepo}. The readonly fork and the gate predicates in React's
own tests evaluate that file as source truth, so any second copy of the flag values is a
divergence waiting to happen.

The codegen must fail closed on drift: if a flag is added, removed, or changes value upstream
and the generated table does not match, the build fails rather than silently emitting a stale
table.

REQUIRED OUTPUT:
{props.schema}
