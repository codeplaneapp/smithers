  exceptions, the cohort landing semantics for the reconciler's import cycle, the panic and
  poisoning policy, and phase-scoped command buffers.

  unions, hook state slots that can hold either a JavaScript reference or a Rust value, packed
  element descriptors consumed internally, and the engine sitting behind a host trait.

type, generation policy, and who may mint it.
