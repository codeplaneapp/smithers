## M8 semantics audit

Audit the campaign repository at {props.repo} against the taxonomy of regressions that a
comparable runtime rewrite hit in production.

Use the publicly documented classes as the checklist. Label each one honestly by provenance:
where a class is published with details, cite it; where only the count is public and the
details are not, say so and do not invent the row. An unauditable checklist is worse than a
short one, because it manufactures confidence.

For every class in the taxonomy, produce one of exactly two things:

1. Evidence that the class cannot occur here, with a permanent test that pins it, or
2. A work item, with the test that would catch it.

"Covered by inspection" is not an answer. If a class is only covered by a human having looked
at it, it is a work item.
