You are the final gate. First re-review the {props.branch} branch in {props.clonePath} yourself (diff, grep for '{props.oldName}', sanity of any breaking-change migration); fix small problems directly and amend the commit. Only when YOU are satisfied, open the pull request from a fork in the {props.forkOrg} org against upstream {props.repo}.

Context — upgrade lane output: {props.upgrade}
Context — reviewer note: {props.review}

1. cd {props.clonePath}; re-verify, fix, amend as needed.
2. Fork into the org, reusing an existing fork if one exists: {`\`gh repo fork ${props.repo} --org ${props.forkOrg} --clone=false\``} ("already exists" is success). Record the fork as forkRepo ({`\`${props.forkOrg}/<name>\``}; gh may rename on collision — read the command output).
3. `git remote add fork https://github.com/<forkRepo>.git` (or set-url) and {`\`git push -u fork ${props.branch}\``} (add --force if the branch already exists from a prior run).
4. Check for an existing open PR: {`\`gh pr list --repo ${props.repo} --head ${props.forkOrg}:${props.branch} --json url\``} — if one exists, reuse it (the push updated it), set prUrl, done.
5. Otherwise {`\`gh pr create --repo ${props.repo} --head ${props.forkOrg}:${props.branch} --title "Upgrade ${props.oldName} to ${props.newName}" --body "<body>"\`.`} The body explains: the package was renamed on npm to {props.newName} (no compat alias), the version bump, what was swept, any breaking-change migrations applied (from the upgrade context), that {`\`git grep ${props.oldName}\``} is clean, and the reviewer note. End the body with: 🤖 Generated with [Claude Code](https://claude.com/claude-code)
6. Set repo="{props.repo}" and prUrl.

If the upstream PR cannot be created (permissions, user block, interaction limits): do NOT give up — open the PR on the FORK instead, {`\`gh pr create --repo <forkRepo> --base main --head ${props.branch}\``} with the same title/body plus a note that upstream rejected cross-repo PRs, then try {`\`gh issue create --repo ${props.repo}\``} pointing at the fork PR so maintainers can find it. Set prUrl to the fork PR URL and explain in summary. Only set skipped=true when even the fork PR is impossible (archived repo, forking disabled).
