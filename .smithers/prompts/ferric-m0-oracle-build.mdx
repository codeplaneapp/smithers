## Build the M0 oracle and the deterministic script layer

Build — or fix, if a previous attempt failed verification — the oracle described in the M0
plan, in the campaign repository at {props.repo}.

The pinned React checkout is at {props.reactRepo}. It is read-only reference material.

## What the compute verifier will execute after you

Every script listed here must exist and be executable: {props.scripts}

The oracle script takes a leg selector: `--unmodified` runs stock React through the runner,
`--ratchet` re-measures after a landing, `--all` runs every cell, and `--leg` takes a named
cohort. Whatever the leg, it prints a line of the form PASSING=n/m, optionally followed by
XFAIL_C=k. The other scripts have the fixed output contracts from the plan.

Also write the signed baseline manifest as `baseline-manifest.json`: file hashes, test
identities with their statuses, config hashes, and flag values.

## The bar

The runner must pass on UNMODIFIED React. A judge that has not proven itself on code known to
be correct is not a judge. Note that a script that merely prints a passing line is worthless:
the verification step exists to catch exactly that, and a stub will be found.
