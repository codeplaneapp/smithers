# Polish approvals and run actions

GitHub: https://github.com/smithersai/smithers/issues/994

Parent: smithers/gh-643-make-smithers-monitor-truly-beautiful-matc-00hgmat.md

Context: pending approvals and lifecycle controls are the monitor's most time-sensitive operator actions. Acceptance criteria: present pending approvals with workflow, run, node, request summary, and wait time; make approve and deny actions visually distinct, confirmation-aware, busy-safe, and error-recoverable; ensure run pause, resume, cancel, retry, and health actions have clear state-dependent affordances; provide accessible names, focus behavior, and tests for success, failure, and stale approval cases.
