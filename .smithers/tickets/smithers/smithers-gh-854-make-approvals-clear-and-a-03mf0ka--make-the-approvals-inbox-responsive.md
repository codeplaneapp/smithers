# Make the approvals inbox responsive

GitHub: https://github.com/smithersai/smithers/issues/956

Parent: smithers/gh-854-make-approvals-clear-and-actionable.md

Context: The inbox must remain usable on narrow browser windows and mobile-sized viewports. Acceptance criteria: The inbox, context, actions, and feedback fit without horizontal clipping at narrow widths; list/detail regions stack or otherwise adapt; approve, deny, confirmation, and error controls remain reachable and readable; desktop and narrow viewport tests verify the layout and decision flow.
