Smithers is a durable workflow framework where you configure workflows using simple TypeScript configuration files and the Smithers engine durably executes them fast.

It is similar to monorepo management tools like TurboRepo, Nx, and Bazel, but while those tools primarily focus on fast CI, Smithers is focused on making useful agentic workflows and helping agents working on the codebase be faster, cheaper, and smarter.

## Get started

Install Smithers and run.

### Installation instructions

Install from npm, use a prebuilt binary, or build from source.
Use the primary option first:

<LinkButton href="../download/" variant="primary">Prebuilt binary</LinkButton>
