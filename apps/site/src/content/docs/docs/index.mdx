Smithers is an agentic workflow framework for defining workflows in simple TypeScript configuration files and executing them quickly, durably, and reliably.

Smithers is similar to monorepo tools like Turborepo, Nx, and Bazel: it helps make work across a codebase fast and efficient.

Fast CI matters even more when agents are doing the work. But traditional monorepo tools largely stop at building and testing code. Smithers extends that model to agentic work, helping agents work on a codebase faster, cheaper, and more intelligently. When the process running a flow stops, Smithers [resumes from the last recorded step](/docs/concepts/durable-execution/) instead of starting the work again.

## Get started

Install Smithers and run.

<LinkButton href="/download/" variant="primary">Prebuilt binary</LinkButton>
<LinkButton href="/docs/installation/" variant="secondary">More install options</LinkButton>

```bash
npm install --global @smthrs/cli@next
```

Then scaffold your first workflow and run it:

```bash
smthrs init change
smthrs up change
```

That creates `flows/change/flow.mdx`, a workflow that lives with your code, and runs it. The [quickstart](/docs/quickstart/) walks through the same steps with what to expect at each one.
