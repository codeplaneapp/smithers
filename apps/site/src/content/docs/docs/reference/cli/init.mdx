## Synopsis

```text
smthrs init [name]
```

## Description

`smthrs init` scaffolds the smallest project a flow can run from: one markdown flow at `flows/<name>/flow.mdx`, plus the empty `.flows/` state directory the project's runs use. In a git or jj repository it also adds `.flows/` to the repository's `.gitignore`, once, and never inside a directory that is not a repository. Reach for it once per project, or again per flow when you want the starter body. It never overwrites an existing flow file, and it performs no other setup: seats resolve from environment keys, so the 0.x `init --global` flag was removed ([what replaced it](/docs/migration/1.0/#init)).

The scaffolded flow declares a `model:` seat chosen from the first provider credential the environment sets, in the order `smthrs doctor` reports them:

- `ANTHROPIC_API_KEY` resolves `anthropic:claude-sonnet-4-5`.
- `OPENAI_API_KEY` resolves `openai:gpt-5.6-sol`. The ChatGPT session `SMITHERS_OPENAI_AUTH=chatgpt` resolves the same seat.
- `OPENROUTER_API_KEY` resolves `openrouter:anthropic/claude-sonnet-4.5`.

With no credential set, the scaffold still declares the default (`anthropic:claude-sonnet-4-5`), and the frontmatter comment names the key to set. A scaffold without a `model:` line would not be launchable at all.

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | no | The flow name: one path segment of letters, digits, `-`, and `_`. Defaults to a slug of the project directory name, or `flow` when that yields nothing. |

## Output

Prints the scaffold record: the flow `name`, the `flowFile` path, whether the file was `created` (`false` when a flow already stood there), the `gitignore` status (`created`, `updated`, `unchanged`, or `skipped` outside a repository), the `stateDirectory`, and the `seat` the flow declares. `--json` prints the same record as JSON.

An invalid name exits 2:

```text
a flow name is one path segment of letters, digits, '-' and '_'; got "<name>"
```

## Exit codes

This verb adds no codes beyond the generic set; an invalid `name` is a usage error and exits 2.
