Patch release: the bin delegation added in 0.16.7 now actually runs.

---

## Fixes

- **`@smthrs/cli` no longer declares a `smithers` bin**.
  Previously both `smthrs` and
  `@smthrs/cli` declared the same `smithers` binary, and
  bun registered the CLI's (pointing straight at `src/index.js`) in
  `node_modules/.bin/`, which meant the delegation wrapper in
  `smthrs/src/bin/smithers.js` from 0.16.7 never ran,
  `bunx` tmp-dir and `.smithers/node_modules/` still materialized two
  React singletons, and `bunx smthrs@latest workflow
  grill-me` on a fresh init kept crashing with `Invalid hook call`.
  Dropping the bin from `@smthrs/cli` makes
  `node_modules/.bin/smithers` unambiguously resolve to
  `smthrs/src/bin/smithers.js`, the delegation fires,
  and the local `.smithers/` install takes over for the actual
  workflow run: one React, one reconciler, one hook dispatcher. The
  CLI package is now a pure library; consumers who want the binary
  install `smthrs`.
