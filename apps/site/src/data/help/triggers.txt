smthrs triggers — Manage durable schedules and manually queued occurrences

Usage: smthrs triggers <command>

Commands:
  disable   Disable future occurrences without cancelling an active run
  enable    Enable future occurrences without cancelling an active run
  fire      Queue one manual occurrence for triggers serve or smthrs serve; approvals remain required
  list      List all durable trigger registrations
  register  Register or update a validated cron trigger from flags or a JSON file
  serve     Run the durable scheduler until interrupted, preserving Control approvals
  show      Show a trigger, its active run and the exact approval payload awaiting a decision

Custom Global Options:
  --audience <auto|human|agent>  Presentation audience; auto detects agent harnesses, CI, and terminals (default: auto)
  --silent                       Suppress progress; retain the result and actionable failures
  --ui <auto|tty|stream|plain>   Terminal renderer: tty draws in place, stream colours without cursor motion, plain prints bare lines; auto shows live human progress; agent, --silent, pipe and dumb-terminal policies take precedence (default: auto)

Global Options:
  --filter-output <keys>              Filter output by key paths (e.g. foo,bar.baz,a[0,3])
  --format <toon|json|yaml|md|jsonl>  Output format
  --full-output                       Show full output envelope
  --help                              Show help
  --llms, --llms-full                 Print LLM-readable manifest
  --schema                            Show JSON Schema for command
  --token-count                       Print token count of output (instead of output)
  --token-limit <n>                   Limit output to n tokens
  --token-offset <n>                  Skip first n tokens of output
