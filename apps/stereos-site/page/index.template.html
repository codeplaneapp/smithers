What the edge allows

A guard exposes four routes. The Smithers RPC surface is not public.

Allowlist

Three workflow ids

Input is chosen server-side.

Capacity

2 concurrent, queued

Extra starts queue. Per IP: 6 starts per 10 minutes.

Authority

Per-run approval token

256 bits, compared in constant time.

Lifetime

5 minute ceiling

The guard cancels anything that outlives it.

Transport

Outbound tunnel only

cloudflared dials out. No inbound port.

Isolation

Loopback gateway

Bearer token in a root-owned 0600 file.
